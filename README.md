# Улак Тартыш — прототип

Браузерная 3D-игра по мотивам кыргызской конной игры кок-бөрү. Матч 2×2, 3 минуты.

```
npm install
npm run dev
```

## Что есть

- Главное меню, «Быстрый матч» (время 1/3/5 минут, сложность ботов, состав от 1×1 до 4×4, погода, поле), настройки, пауза, экран результата.
- Языки: русский и кыргызский.
- Настройки: управление на сенсорном экране (джойстик / фиксированный джойстик / езда к точке касания, размер кнопок, режим для левши), автосмена всадника, громкость, вибрация, качество графики, камера, имена над всадниками, имя игрока.
- Локальная статистика матчей (хранится в браузере).
- Онлайн, вход через Google/почту, рейтинг и голосовой чат пока не сделаны — для них нужен сервер.

## Управление

| Действие | Клавиатура | Сенсорный экран |
| --- | --- | --- |
| Езда | W A S D / стрелки | джойстик или касание поля |
| Рывок | Shift | «Рывок» |
| Взять улак / отбор / бросок (удерживать — сила) | Пробел | большая кнопка |
| Пас напарнику | E | «Пас» |
| Финт (уход в сторону) | F | «Финт» |
| Сменить всадника | Q | автоматически |
| Камера / качество графики / пауза | C / G / Esc | кнопки вверху и настройки |

## Структура

- `src/config.js` — размеры поля, скорости, параметры броска, команды
- `src/scene/` — рендерер, небо/свет/туман, горы, юрты, поле и казаны, процедурные текстуры
- `src/entities/` — `HorseModel` (скелетный конь, смешивание стойка/шаг/галоп), `RiderFigure` (скелетный всадник, поза по костям, калпак), `Horseman` (сущность), `Ulak`
- `src/game/` — `Match` (правила, без зависимости от рендера), `Input`, `CameraRig`, `Hud`, `AimGuide`
- `src/physics/PhysicsWorld.js` — мир Rapier: улак как твёрдое тело, сетки казанов, кинематические тела коней
- `src/ai/BotBrain.js` — ИИ ботов
- `src/ui/` — меню (`Menu`), настройки (`settings`), переводы (`i18n`)
- `src/game/TouchControls.js`, `Minimap.js`, `Audio.js` — сенсорное управление, мини-карта, синтезированный звук

Всадником управляет объект `controls` (`throttle/steer/sprint/action`): его заполняет клавиатура или ИИ,
позже — сеть. `Match.update(dt)` не трогает DOM и рендер, его можно перенести на сервер.

Отладка в консоли: `window.__game` (match, riders, ulak, `freeCam`).
